# ADR-0020 Product name "Ariadne" and an industrial design language

**Context.** The working title "ALMlight" described the technology, not the value, and sounded like a reduced product.
End users moving from enterprise PLM/ALM suites should feel at home quickly.

**Decision.** The product is called **Ariadne** — after Ariadne's thread, the guide through the labyrinth (in German
the "Ariadnefaden"): traceability from need to test, through variants and changes. The mark shows a thread winding out
of a labyrinth. "almlight" remains the technical code name (Python package, environment variables, Docker images,
webhook headers, Word/ReqIF identifiers), so existing installations, integrations and round-trip files keep working.
The UI adopts the visual language engineers know from enterprise PLM suites without copying any vendor's branding:
dark navy header with app launcher, project context and central search; grouped left navigation (collapsible to an
icon rail); a "My workspace" home with tiles; object headers with type tile, identity chips and a command bar; dense
tables; documents as paper sheets; petrol-teal accent, Inter typeface, small radii; light and dark themes.

**Consequences.** + Recognisable, calm, professional UI; users from enterprise suites find the familiar structure.
+ No migration needed for technical identifiers. − Trademark clearance of the name is required before commercial
use.
